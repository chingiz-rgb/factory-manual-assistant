# CNC Lathe CL-200 Operation Manual

> Sample manual written for the Factory Manual Assistant demo. The machine "CL-200" and all values are fictional.

## 1. Before Starting the Machine

Complete this checklist at the start of every shift. Do not start the spindle until every item is confirmed.

1. Wear safety glasses and safety shoes. Do not wear gloves, loose sleeves or jewelry near the rotating chuck.
2. Check that the hydraulic pressure gauge reads between 3.0 and 3.5 MPa.
3. Check the coolant level. It must be above the MIN line on the tank window.
4. Check the lubrication oil tank. Refill with ISO VG 32 oil if it is below the half mark.
5. Make sure the chuck key has been removed from the chuck.
6. Close the front door. The spindle will not start while the door is open (interlock).
7. Run the spindle warm-up program O9000 for 10 minutes if the machine has been off for more than 8 hours.

## 2. Spindle Speeds and Limits

The maximum spindle speed of the CL-200 is 4,000 min⁻¹. Never exceed the limit of the chuck or the workpiece, whichever is lower.

| Chuck size | Maximum speed |
|---|---|
| 6-inch chuck | 4,000 min⁻¹ |
| 8-inch chuck | 3,500 min⁻¹ |
| 10-inch chuck | 2,500 min⁻¹ |

When the jaws are extended beyond the chuck outer diameter, reduce the maximum speed by 30%.

## 3. Tool Change

### 3.1 Turret Tool Holders

1. Press EMERGENCY STOP before reaching into the turret area.
2. Loosen the two M8 clamp bolts of the tool holder with a 6 mm hex key.
3. Insert the new tool so that the tip is at center height. Use the height gauge supplied with the machine.
4. Tighten the M8 clamp bolts to 25 N·m with the torque wrench. Do not use an extension pipe.
5. Enter the new tool offset on the TOOL OFFSET screen and run the first part in single-block mode.

### 3.2 Tool Offset Check

After a tool change, measure the first part. If the diameter is out of tolerance by more than 0.02 mm, correct the wear offset and measure again.

## 4. Coolant

Use water-soluble coolant at a concentration of 5–8%. Check the concentration with the refractometer every Monday. If the coolant smells bad or has oil floating on top, report it to maintenance. Coolant is replaced every 3 months.

## 5. Alarm Codes

| Code | Meaning | What to do |
|---|---|---|
| E-11 | Door open during operation | Close the door and press RESET. |
| E-21 | Spindle overload | Stop the program. Check for a worn or broken tool and reduce the depth of cut. If the alarm returns, call maintenance. |
| E-35 | Low hydraulic pressure | Check that the gauge reads 3.0–3.5 MPa. Do not operate the chuck. Call maintenance. |
| E-40 | Lubrication oil low | Refill the lubrication tank with ISO VG 32 oil and press RESET. |
| E-52 | Turret not clamped | Press RESET and index the turret again. If it repeats, do not run the machine. Call maintenance. |

## 6. Shutdown

1. Remove chips from the chuck and the turret with a brush. Never use compressed air toward your face or other workers.
2. Move the turret to the home position.
3. Turn off the main power switch at the end of the last shift.
